## Global bindings

`var`/`function` declarations become `window` properties in a plain (non-module) `<script>`
tag and stay reachable if later split across multiple `<script src>` files loaded in order.
**`let`/`const` do NOT** — they are scoped to the single `<script>` tag that declares them and
become invisible to any other file the moment this script is split, unless explicitly attached
to a shared object (e.g. `window.X`) or kept together. This applies to `NAV_GROUPS`, `activeTab`,
`STATE`, `currentUser`, and every other `let`/`const` binding below — each is a concrete blocker
for whichever Phase 3 split first tries to separate its declaring section from its readers.
